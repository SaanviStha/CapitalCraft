CAPITAL CRAFT - Web-Based Learning System
CT050-3-2-WAPP Web Applications - Group Assignment
Team: Roshni K. Shah, Saanvi Shrestha, Sadiksha Timsina, Shirsha Bhandari

Capital Craft is a learning website where members can sign up, enrol in courses about building and launching ventures, read the lessons and take a quiz for each course.
Admins can add and edit courses, lessons, quiz questions and users.
We made it in Visual Studio 2022 as an ASP.NET Web Forms project using C# and .NET Framework 4.8, with HTML, CSS and JavaScript for the pages.
All the data is stored in a SQL Server LocalDB database (App_Data\CapitalCraft.mdf).

Note: the database files (App_Data\CapitalCraft.mdf and .ldf) are not included in this repository. Create the database with SQLQuery1.sql and SQLQuery2.sql, then run the Add*.sql scripts to load the course content.
